The states a week strip gets wrong
Each of these is a case where the obvious implementation — loop 1…mesocycleWeeks, mark trained weeks — reports something false. The scope line is the same component in every one; only its sentence changes.
1
Draft — never started
Nothing scheduled yet. Every session follows the plan as you leave it.
No badges at all. There are no workout rows, so a trained-state indicator here would be computed from nothing — noise dressed as information. The scope line still appears, so the surface never changes shape between states.
2
Block complete
Block complete — all 24 sessions trained. Edits apply the next time you run this block.
The trap: complete does not mean read-only. The program stays active, the final week is re-runnable, and a re-run is a fresh instantiation — so edits made now do land. Saying “this block is finished, nothing to edit” would be wrong twice over.
3
Shortened below trained weeks
This block is now 4 weeks, but you trained into weeks 5–6 before it was shortened. That training still counts and still shows in your history.
WK 1–4 + WK 5–6 · TRAINED, PAST THE END
The one that silently loses data. Anything that iterates 1…mesocycleWeeks drops weeks 5–6 from view entirely — real sessions, invisible. The list has to be driven by trained history, not by the bound.
4
Archived
Archived. Edits are saved, and take effect if you make this program active again.
Nothing in the code blocks editing an archived program — no status check exists on any patch path. So the surface may not say “archived programs are read-only”; that would describe a lock that was never built. Either state what actually happens, as above, or build the guard first.
One predicate behind every state
A session is settled when it has been started — not when its week has passed, and not when the block is over.
Everfit ships the same rule in production: changes reach workouts “today and onwards that have not yet been logged.” Per-session, gated on started-ness. It is the only published prior art that matches, and it matches exactly.
