# Analytics Identity Notice

If you turn this on, we link your product usage to your account so we can see
which features people like you actually use — which screens, how often, and
whether the app is helping you build a training habit.

What this never includes: your exercises, weights, body-weight entries,
photos, or notes. Analytics carries only counts, durations, and coarse
categories (for example: "a workout with 5 exercises was completed").

This is off by default. You can turn it off at any time in Settings, and when
you do, we also delete the usage profile our analytics provider holds. If
your browser sends a Global Privacy Control signal, this stays off
automatically.
