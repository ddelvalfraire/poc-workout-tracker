## Criticals

Z1. **Program immutability** (A-C2, C-1). The seven in-place-rebound programs
    (prog/gzclp-t1, opt-strength-endurance, opt-loaded, opt-power, legs-3x,
    hr-tempo-block, achilles-loading) republish as @2 binding lib/*@2; their @1
    bodies are restored byte-exact to the patfix-era kit (same independent byte-check
    discipline as defs-v1). `publish()` REFUSES a changed body at an existing

    convention). cfgfix.test.ts:135's pin of the in-place hash move is corrected.
    Sweep for ANY other ref whose body changed across rounds under a constant version.
Z2. **One form per meaning, per entry** (A-C1, C-3, B-W2). Record options refuse
    PER-ENTRY defaults (volumeWeights {stage:0.5,cluster:0.8} → refuse the stage
    entry; staleness entries equal to the registry value likewise). maxReps >=
    formula domainMax refused (A: the > check lets the edge through). strip lists
    equal IN EFFECT to the default (intersected with the calendar's roles) refused.
    An explicit read-level formula equal to the program's effective formula refused.
    The ledger records the remaining class honestly: one-form is syntactic for
    computed terms (canonical-JSON), with the two accepted second forms named as a
    CLASS. labels:{} refused like defaults:{} (B nit).
Z3. **The declared inverse honors the declared cap, symmetrically** (A-C3, B-W3,
    C-5). loadForInverse applies the program's maxReps for EVERY formula, Epley
    included (the special case must not be skipped when formula==='epley' AND
    maxReps is declared); out-of-cap/domain input → typed absence, never a number
    the forward read refuses. Lombardi at effective reps 0 → absent, never Infinity
    (guard like the forward read's r<=0 skip). The interception keys on
    lib/load-for@1 EXACTLY (version checked); a hypothetical @2 runs its own body;
    the seam is documented in SPEC as bound to @1. e1rmConsumed also scans policy
    plan Uses (B-W1).
Z4. **atLeastSets is monotone and never vacuous** (A-C5 parent-confirmed, C-6).
    The LAW to implement and pin as a property test: logging more sets can never
    worsen the verdict. Rule: count hit sets among ALL logged judged sets (extras
    included, consistent with totalReps pooling); the cap is the plan's ISSUED
    ceiling (count.n; range max; until/while max), never logged.length; hit when
    hitSets >= min(n, cap); missed only when even if every remaining issuable set
    hit it could not reach min(n, cap); unknown otherwise (early stop on an until
    step is unknown, not hit). Prose (successText) states the cap behavior.
    OWNER-OVERRIDABLE: extras counting toward atLeastSets.
Z5. **Dead-config scan sees every consumer** (B-C1, parent re-ran P-G; P-A trace
    accepted). The slot-success consumption scan includes the program aggregate's
    handlers and policy plan Uses; B's P-A program (aggregate verdict read consuming
    a slot rule) checks CLEAN and its verdict flips under the rule (regression from
    B's P-A2). Same widening for the read-level-'allSets'-with-no-slot-rule flag
    (W2a): flag it with the same machinery rather than accepting silently.
Z6. **Static atLeastSets checks never refuse a satisfiable configuration** (B-C2,
    parent-confirmed). Scheme-level: a defaulted count is NOT its default for
    refusal purposes (skip, or bound by type); only refuse what is unsatisfiable
    under EVERY legal binding. Program-level (args substituted) stays. The checks'
    plan-only blindness to addSets-via-policy/phase is handled the same way:
    provably-unsatisfiable only. The duplicated maxJudgedSets block is ONE helper
    whose role/step scoping matches the judge's actual semantics (A-W4).
Z7. **Grids are positive quantity literals, everywhere** (A-C4, B-C3, C-7
    consensus). Slot AND program grid terms must be q-literals with n > 0; zero,
    negative, and computed terms are typed refusals (the SPEC already claims
    "closed literal"). This makes the one-form respelling comparison well-defined
    and kills the display:{} hole (a stamped slot grid ALWAYS carries its unit).
    Fix the mistitled units test (C-7: the "same value in the other unit" case must
    construct a genuine lb-unit literal, i.e. value in the grid's own unit).

    conversion IS display-only and session text is a prose projection; the

    change. OWNER-OVERRIDABLE (the alternative — viewer conversion skips
    grid-bearing numbers — is recorded as the rejected option).
Z9. **Make-up sets must honor the step's other bars to pay in** (A-W1).
    A logged set beyond the expected count pays reps into totalReps ONLY if every
    non-reps bar of the step it extends holds for it (an empty-bar 30-rep set
